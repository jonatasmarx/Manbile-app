# MANBILE

Aplicativo Android desenvolvido para auxiliar na gestão de atividades de técnicos de telecomunicações.

O MANBILE permite visualizar atividades de campo, consultar seus detalhes, registrar diagnósticos e acompanhar informações relacionadas aos serviços executados pelos técnicos.

## Objetivo

O projeto tem como objetivo aplicar conceitos de desenvolvimento mobile por meio da criação de um aplicativo Android funcional, com foco em usabilidade, organização das informações e integração com API externa.

## Funcionalidades

- Tela de splash
- Tela de login
- Dashboard principal
- Listagem de atividades
- Visualização dos detalhes das atividades
- Registro de diagnóstico
- Persistência de informações
- Navegação entre as telas
- Consulta de endereço por CEP
- Integração com API externa

## Integração com API

O aplicativo utiliza a API ViaCEP para consulta de endereços a partir do CEP informado pelo usuário.

A comunicação com a API é realizada utilizando Retrofit.

## Tecnologias utilizadas

- Java
- Android Studio
- XML
- Gradle
- Retrofit
- API ViaCEP
- Git

## Plataforma

Aplicativo desenvolvido de forma nativa para Android.

## Sobre o projeto

O MANBILE foi projetado como uma solução para o contexto de empresas de telecomunicações, auxiliando técnicos no gerenciamento de atividades de manutenção corretiva, preventiva e serviços de campo.

O projeto contempla conceitos de UX/UI, desenvolvimento Android nativo, persistência de dados e comunicação com serviços externos por meio de API.
